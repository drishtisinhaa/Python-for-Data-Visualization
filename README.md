# Data Visualization with Python - Matplotlib and Seaborn  

## 📌 Project Overview  
This project explores data visualization techniques using **Matplotlib** and **Seaborn**. It covers different types of plots, customization techniques, and best practices for effective data representation.  

## 📊 Key Topics Covered  
1. **Line Plots** - Customizing color, width, and style  
2. **Scatter Plots** - Relationship between variables  
3. **Bar Charts & Histograms** - Comparing categories and distributions  
4. **Box Plots & Violin Plots** - Identifying outliers and distributions  
5. **Heatmaps** - Correlation analysis using Seaborn  
6. **Customization & Styling** - Themes, annotations, and advanced formatting  

## 🛠️ Technologies Used  
- **Python** (Pandas, NumPy)  
- **Matplotlib** (for basic plotting)  
- **Seaborn** (for advanced visualization)

## 🛠️ Setup & Installation  
1. Clone the repository:  
   ```sh  
   git clone https://github.com/yourusername/Data_Visualization_Python.git  
   ```  
2. Install dependencies:  
   ```sh  
   pip install pandas numpy matplotlib seaborn jupyterthemes  
   ```  
3. Run the Jupyter Notebook:  
   ```sh  
   jupyter notebook "Data Visualization with Python - Matplotlib and Seaborn.ipynb"  
   ```
